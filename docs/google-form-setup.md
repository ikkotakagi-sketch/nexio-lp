# Googleフォーム連携セットアップガイド

ネクシオグループLPのお問い合わせフォームをGoogleフォームに接続し、回答をスプレッドシートに自動保存する手順です。

## Step 1: Googleフォームの作成

1. [Google Forms](https://forms.google.com) にアクセス
2. 「空白のフォーム」から新規作成
3. 以下のフィールドを追加：
   - **会社名**（記述式）
   - **お名前**（記述式）
   - **メールアドレス**（記述式）
   - **電話番号**（記述式）
   - **ご相談内容**（プルダウン）: 人材派遣・紹介 / ビザ・在留資格申請 / 労務管理・助成金 / 技能実習・特定技能 / その他
   - **詳細**（段落）

## Step 2: スプレッドシート連携

1. フォーム編集画面の「回答」タブをクリック
2. 「スプレッドシートにリンク」の緑アイコンをクリック
3. 「新しいスプレッドシートを作成」→ 作成
4. スプレッドシートをGoogleドライブの任意のフォルダに移動

## Step 3: フォームをLPに埋め込む

1. フォーム編集画面 → 「送信」ボタン → 「<>」埋め込みタブ
2. 表示されるiframe URLをコピー（例: `https://docs.google.com/forms/d/e/XXXXXXXXX/viewform?embedded=true`）
3. `nexio.html` の以下の行を修正:
```html
src="https://docs.google.com/forms/d/e/YOUR_FORM_ID/viewform?embedded=true"
```
→ `YOUR_FORM_ID` 部分を実際のIDに置き換え

これで、フォーム送信データは自動的にスプレッドシートに蓄積されます。
